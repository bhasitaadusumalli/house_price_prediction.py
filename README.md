# House Price Prediction

## Description
A machine learning project built during my internship at 
Codtech IT Solutions that predicts house prices based on 
features like location, size, number of bedrooms, and 
other factors using Python and ML algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## How to Run
1. Clone the repository
2. Install required libraries:
   pip install pandas numpy scikit-learn matplotlib seaborn
3. Open the project in VS Code
4. Run: python house_price_prediction.py
